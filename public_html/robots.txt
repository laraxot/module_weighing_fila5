# Su un sito che segnala un disservizio alla pubblica amministrazione, indicizzare le
# pagine di prova significa esporre contenuti non revisionati. Il rischio qui non e'
# teorico: `/it/prova01` contiene 172 occorrenze di testo in italiano non tradotto,
# il doppio di qualunque pagina pubblicata.
#
# `Disallow` NON e' una protezione: un crawler rispettoso lo segue, ma il contenuto
# resta pubblico. Serve a non farlo indicizzare, non a nasconderlo. Per chiudere
# davvero serve rimuovere le pagine di prova dal percorso pubblico: vedi
# `Modules/Fixcity/docs/bmad/stories/STORY-517-design-comuni-coverage.md`.
#
# SINTASSI
# =======
# Il file segue la grammatica di Google: `Disallow:` vuoto significa "nessun
# vincolo". I pattern sono prefissi, e `*` non e' un carattere jolly ma un
# letterale: per escludere `/it/tests` e le sue sottopagine serve la riga senza
# `*` finale, che li esclude per intero.
