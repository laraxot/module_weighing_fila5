# Theme documentation

Each front-office theme owns its documentation under
`laravel/Themes/<Theme>/docs/`.

Theme documentation is the source of truth for Vite, CSS, reusable blocks,
JSON-driven content, responsive parity and browser verification. Do not place
new theme implementation notes in root `bmad-output/`.

Every visual or build claim must state its route, viewport, command and result.
Screenshots are evidence, not a substitute for computed styles, font loading,
network responses and the generated manifest.

See [Sixteen docs](./Sixteen/docs/INDEX.md) and
[project documentation governance](../../docs/DOCUMENTATION_GOVERNANCE.md).
