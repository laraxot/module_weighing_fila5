# BMAD Story — CMT-014: Rimozione riferimenti pacchetti Spatie dal modulo Comment

Status: completed
Module: Comment
Created: 2026-10-16
Tags: [bmad, story, cleanup, spatie, composer, ponytail, strangler-fig]

## Understand

### Problema
Il modulo Comment ha completato la migrazione da pacchetti Spatie (`spatie/laravel-comments`, `spatie/laravel-comments-livewire`) a implementazione custom, ma `composer.json` contiene ancora riferimenti all'autoload dei pacchetti sotto `packages/spatie/`.

### Contesto
La directory `packages/spatie/` è già stata eliminata dal filesystem (vedi git status: centinaia di file `deleted by us`). Tuttavia `composer.json` conserva:
```json
"Spatie\\Comments\\": "packages/spatie/laravel-comments/src",
"Spatie\\LivewireComments\\": "packages/spatie/laravel-comments-livewire/src"
```

Questi riferimenti puntano a path inesistenti → potenziali errori di autoload/class-not-found.

### Principio Ponytail
Rimuovere ciò che non serve più. Non mantenere riferimenti a codice eliminato. Strangler fig completato: il custom Comment module sostituisce pienamente i pacchetti Spatie.

## Plan
1. Rimuovere le due righe di autoload `Spatie\\*` da `Modules/Comment/composer.json`
2. Eseguire `composer dump-autoload` per rigenerare il classmap
3. Verificare che nessun file nel modulo Comment faccia ancora riferimento a classi `Spatie\Comments\*` o `Spatie\LivewireComments\*`

## Implement
- Action 1: Modificare `Modules/Comment/composer.json` — rimuovi blocco Spatie da `autoload.psr-4`
- Action 2: `composer dump-autoload` (root laravel)
- Action 3: `grep -rn "Spatie\\\\Comments\\|Spatie\\\\LivewireComments" Modules/Comment/app/` — verifica zero riferimenti

## Verify
- `grep -rn "Spatie\\\\Comments\\|Spatie\\\\LivewireComments" Modules/Comment/` → zero risultati (escluso vendor)
- `composer dump-autoload` senza errori
- `phpstan analyse Modules/Comment` → 0 errori (o errori preesistenti non introdotti da questa rimozione)

## Document

- Aggiornare `Modules/Comment/docs/bmad/bmad-dossier.md` — nota completamento migrazione Spatie → custom
