# CMT-018 — Eliminare Http/Livewire del modulo Comment

Status: **done** (2026-10-16)

## Story

As a maintainer, I want `Http/Livewire` removed from Comment so that only
Filament widgets remain as FO UI entry points.

## Acceptance Criteria

1. Directory `Modules/Comment/app/Http/Livewire` absent.
2. Directory `Modules/Comment/resources/views/livewire` absent.
3. Zero runtime references to `CommentsComponent` / `CommentComponent`.
4. FO uses only `Filament\Widgets\Commentable\CommentsWidget`.

## Owned Scope

- `Modules/Comment/app/Http/Livewire/**` (deleted)
- `Modules/Comment/resources/views/livewire/**` (deleted)
