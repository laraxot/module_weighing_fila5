# CMT-021 — E2E / Pest submit commenti FO

Status: **ready-for-dev**

## Story

As a QA agent, I want automated coverage that an authenticated user can submit
a comment on blog, event and ticket, so that regressions on empty-thread mounts
cannot return.

## Acceptance Criteria

1. Pest feature: auth submits on Article `content_type=post`.
2. Pest feature: auth submits on Article `content_type=event`.
3. Pest feature: auth submits on Ticket.
4. Guest cannot create (policy / form absent).
5. Empty-thread case covered for post and event.
