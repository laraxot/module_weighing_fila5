# BMAD Story — CMT-010: User model implementa CanComment per abilitare commenti

Status: ready-for-dev
Module: Comment + User
Created: 2026-10-16
Tags: [bmad, story, user, cancomment, comment, authentication, logged-in]

## Understand

### Problema
Il modulo Comment esiste ed è pienamente funzionante a livello backend, ma il modello `User` non implementa il contratto `CanComment`. Di conseguenza:
- Il metodo `HasComments::comment()` riceve `?CanComment $commentator` ma `auth()->user()` restituisce un `User` che non implementa `CanComment` → PHP TypeError
- `CommentEngineServiceProvider::resolveCommentateurModel()` esce presto perché `! is_subclass_of($userClass, CanComment::class)`
- I commenti non possono essere creati da utenti loggati su blog, eventi e ticket

### Root cause
`BaseUser` (Modules\User\app\Models\Models\BaseUser.php) non usa il trait `InteractsWithComments` né implementa `CanComment`.

## Plan
1. Aggiungere `use Modules\Comment\Models\Concerns\InteractsWithComments;` a `BaseUser`
2. Aggiungere `implements CanComment` alla dichiarazione classe `BaseUser`
3. Aggiungere import `use Modules\Comment\Models\Contracts\CanComment;`
4. Aggiungere `../Comment` come path repository in `Modules/User/composer.json`
5. Eseguire `composer dump-autoload` dal root laravel
6. Verificare che `auth()->user()` sia istanza di `CanComment`

## Implement
- Action 1: Modificare `Modules/User/app/Models/Models/BaseUser.php` — trait + implements + import
- Action 2: Modificare `Modules/User/composer.json` — aggiungi repository Comment
- Action 3: `composer dump-autoload` (root laravel)
- Action 4: Tinker check `auth()->user() instanceof CanComment`

## Verify
- `php -d memory_limit=2048M vendor/bin/phpstan analyse Modules/User --no-progress` → 0 errori
- `php artisan tinker --execute 'var_dump(auth()->user() instanceof Modules\Comment\Models\Contracts\CanComment;'` → true (con utente loggato)
- Test feature: creare commento su Article e Ticket con utente autenticato

- Utente può modificare/eliminare i propri commenti
