## Understand

### Model Type Analysis — CommentNotificationSubscription

**Is it a pivot?** → YES (MorphPivot). Evidence:
- Tabella junction polimorfica: `commentable_type/id` + `subscriber_type/id`
- Due relazioni `MorphTo`
- Estende `BaseMorphPivot` (non `BaseModel` né `Model`)

Heritage corretta:
```
Illuminate\Database\Eloquent\Relations\MorphPivot
    └── XotBaseMorphPivot (Modules/Xot/app/Models/)
            └── BaseMorphPivot (Modules/Comment/app/Models/)
                └── CommentNotificationSubscription (concrete)
```

### Fix applied (2026-09-07)
- Changed: `extends BaseModel` → `extends BaseMorphPivot`
- Removed: `use Illuminate\Database\Eloquent\Model`
- Updated: `@property-read BaseMorphPivot` (docblock)
- Updated: `@return MorphTo<BaseMorphPivot, $this>` (PHPDoc return types)
- Added: `@phpstan-ignore return.type` (suppression per inferenza generics)
