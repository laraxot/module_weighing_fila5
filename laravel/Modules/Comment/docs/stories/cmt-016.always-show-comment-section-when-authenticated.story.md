# CMT-016 — Sempre montare CommentsWidget su blog/eventi

Status: **done** (2026-10-16)

## Story

As a cittadino autenticato, I want to comment on a novità/evento even when
there are no approved comments yet, so that I can start civic dialogue.

## Acceptance Criteria

1. `blog/detail.blade.php` mounts `CommentsWidget` without `@if ($comments->isNotEmpty())`.
2. `events/detail.blade.php` same.
3. Auth: `readOnly => false`; guest: `readOnly => true` + login CTA.
4. Props: `commentableType`, `commentableKey` (not `writable`).
5. No `Http/Livewire` references.

## Owned File/Module Scope

- `Themes/Sixteen/resources/views/components/blocks/blog/detail.blade.php`
- `Themes/Sixteen/resources/views/components/blocks/events/detail.blade.php`
