# BMAD Story — CMT-015: Conversione CommentsComponent (Livewire) in CommentsWidget (Filament)

Status: completed
Module: Comment
Created: 2026-10-16
Tags: [bmad, story, filament, widget, conversion, livewire-removal, frontend]

## Understand

### Problema
Il modulo Comment aveva due implementazioni parallele della stessa logica:
- `CommentsComponent` (Livewire, `Modules\Comment\Http\Livewire\CommentsComponent`) — usato nelle viste frontend (blog, eventi, ticket)
- `CommentsWidget` (Filament, `Modules\Comment\Filament\Widgets\Commentable\CommentsWidget`) — usato nel pannello admin

Il principio "non utilizziamo più componenti Livewire ma Filament widget" richiede di eliminare la duplicazione e usare esclusivamente `CommentsWidget` ovunque.

### Root cause
Esistenza di due classi che fanno la stessa cosa (lista commenti, form inserimento, notifiche, reazioni) ma con gerarchie diverse (`Livewire\Component` vs `Filament\Widgets\Widget` → `XotBaseWidget`).

### Decisione
Usare `CommentsWidget` (Filament) come SSOT per il frontend. Rimuovere i riferimenti a `CommentsComponent` dalle viste Blade.

## Plan
1. Sostituire `@livewire(\Modules\Comment\Http\Livewire\CommentsComponent::class)` con `@livewire(\Modules\Comment\Filament\Widgets\Commentable\CommentsWidget::class)` in:
   - `Themes/Sixteen/resources/views/components/blocks/blog/detail.blade.php`
   - `Themes/Sixteen/resources/views/components/blocks/events/detail.blade.php`
   - `Modules/Fixcity/resources/views/components/ticket-comments.blade.php`
2. Verificare che nessun altro file faccia riferimento a `CommentsComponent`
3. Mantenere `CommentsComponent` come classe deprecata (non eliminare per non rompere riferimenti esterni eventuali)

## Implement
- Action 1: Modificare `blog/detail.blade.php` — usa `CommentsWidget`
- Action 2: Modificare `events/detail.blade.php` — usa `CommentsWidget`
- Action 3: Modificare `ticket-comments.blade.php` — usa `CommentsWidget` (sostituendo anche componenti Spatie rimossi)
- Action 4: Verifica grep zero riferimenti a `CommentsComponent` nelle viste
