# BMAD Story — Fix CommentNotificationSubscription extends BaseMorphPivot

## Understand
- **Problem**: `CommentNotificationSubscription.php` estendeva direttamente `Illuminate\Database\Eloquent\Model` invece di usare il pattern di ereditarietà corretto del modulo.
- **Root cause**: Il modello è un pivot (ha relazioni morphTo) ma era stato fatto estendere Model direttamente invece di BaseMorphPivot.
- **Applicable rules**: `phpstan.neon` non può essere modificato. Nessuna soppressione consentita. Mixed solo dopo aver esaurito tipi alternativi. `declare(strict_types=1);` su ogni file. Pattern ereditarietà corretto: CommentNotificationSubscription → BaseMorphPivot → XotBaseMorphPivot → Model.

## Plan
1. Modificare CommentNotificationSubscription.php per estendere BaseMorphPivot invece di Model
2. Rimuovere `use Illuminate\Database\Eloquent\Model;` import
3. Rimuovere `use HasXotFactory;` import (ridondante, già in XotBaseMorphPivot)
4. Aggiornare PHPDoc con tipi corretti per MorphTo
5. Eseguire phpstan su Modules/Comment per confermare 0 errori
6. Eseguire quality gate
7. Git sync

## Implement
- Action 1: Modificare CommentNotificationSubscription.php per estendere BaseMorphPivot
- Action 2: Rimuovere import ridondanti
- Action 3: Aggiornare PHPDoc @property-read con BaseMorphPivot

- Action 5: Correggere test ListCommentsTest.php per usare getTableActions() invece di getActions()
