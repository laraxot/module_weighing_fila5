# CMT-020 — Accessibilità sezione commenti FO

Status: **ready-for-dev**

## Story

As a cittadino con esigenze di accessibilità, I want the comment form and list
to meet WCAG 2.1 AA, so that civic dialogue is inclusive.

## Acceptance Criteria

1. Visible/`for` labels on textarea and submit.
2. Error messages associated and focusable.
3. Contrast AA on FO surfaces (Sixteen + widget).
4. Keyboard-only submit path works.
5. Empty state has `role=status` or equivalent.

## Owned Scope

- `Modules/Comment/resources/views/filament/widgets/commentable/**`
- `Modules/Comment/lang/{it,en}/txt.php` (copy only)
- Sixteen detail blades (aria only if needed)
