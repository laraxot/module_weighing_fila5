# BMAD Story — CMT-012: Commenti su eventi (frontend)

Status: ready-for-dev
Module: Comment + Blog + Sixteen theme
Created: 2026-10-16
Tags: [bmad, story, events, comments, frontend, livewire, article]

## Understand

### Problema
Le pagine di dettaglio degli eventi (`events/[slug].blade.php` → `pub_theme::blocks.events.detail`) mostrano i commenti esistenti in HTML statico ma non offrono un modulo per aggiungere nuovi commenti agli utenti loggati.

### Contesto
Gli eventi sono articoli del blog con `content_type = 'event'` (visto in `Blog\Http\Livewire\Article\Lists::getArticleQuery()`: `whereIn('content_type', ['post', 'event'])`). Il modello `Article` implementa già `Commentable` e usa `HasComments`.

### Modello di riferimento
Stesso pattern di CMT-011: sostituire HTML statico con `CommentsComponent` Livewire.

## Plan
1. Sostituire il blocco HTML statico dei commenti in `events/detail.blade.php` con `@livewire(\Modules\Comment\Http\Livewire\CommentsComponent::class, ['model' => $event, 'writable' => true])`
2. Verificare che il componente riceva il modello `Article` (evento) e renderizzi lista + form per utenti autenticati

## Implement
- Action 1: Modificare `laravel/Themes/Sixteen/resources/views/components/blocks/events/detail.blade.php` — sostituire blocco commenti statico con Livewire component
- Action 2: Verificare rendering su URL `/events/[slug]` con utente loggato e non loggato

## Verify
- Caricare pagina `/events/some-slug` con utente loggato → appare textarea per commento
- Caricare pagina con utente non loggato → nessun form
- Inviare commento su evento → commento associato all'Article con content_type='event'
- `phpstan analyse` → 0 errori
