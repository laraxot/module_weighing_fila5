# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities to the project maintainer via the GitHub Security Advisory system or by emailing security@laraxot.com.

When submitting a report, please include:
- Steps to reproduce the issue
- Expected vs actual behavior
- Any relevant code snippets or logs
- Version of the software affected

We will acknowledge receipt of your report within 48 hours and provide a timeline for resolution.

## Disclosure Policy

Once a vulnerability is confirmed, we will:
1. Acknowledge the reporter privately
2. Work on a fix in a private branch
3. Coordinate a public disclosure timeline
4. Release a patch and security advisory
5. Credit the reporter (if desired)

Thank you for helping keep this project secure!
